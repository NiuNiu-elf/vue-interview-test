# Windows 风格计算器 (Vue 3 + Vite)

这是一个基于 Vue 3 和 Vite 构建的 Web 计算器，高度还原了 Windows 系统自带计算器的界面与核心交互。

## 功能特性
- 基础的加减乘除四则运算
- 支持连续运算（如 1 + 2 + 3 = 6）
- 支持键盘输入（数字、运算符、Enter 计算、Esc/C 清空）
- 完善的异常处理（如除以 0 提示）
- 还原 Windows 计算器深色主题与网格布局

## 开发思路与 Git 提交规范
本项目严格按照阶段拆分开发：
1. **布局阶段**：从外壳、网格到按钮逐步搭建。
2. **逻辑阶段**：从数字显示、清除、暂存状态到等号计算，一次提交只解决一个行为逻辑。
3. **样式阶段**：逐步微调按钮跨度、强调色与交互反馈。

详细的 AI 辅助开发对话记录已归档至 `ai-logs/` 目录，可按 commit 记录对应查看。
